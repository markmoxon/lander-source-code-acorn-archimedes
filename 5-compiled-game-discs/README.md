# Compiled game discs for Lander on the Acorn Archimedes

This folder contains the final disc files for Lander on the Acorn Archimedes, as produced by the build process.

There is one disc image (lander.adf) for the game, which contains both the Arthur and RISC OS versions, and there is another disc image containing the source (lander-source.adf). The source is a is a BBC BASIC text file that will build Lander on an Archimedes.

These files can be loaded into an emulator like Arculator, or into a real Archimedes using a device like a Gotek.
